# Astro Chaos 🚀

An infinite, smooth spaceship shooter. Fly, auto-fire, blow up falling aliens, level up and spend
skill points on silly upgrades, then flex on the leaderboard.

- **Infinite run** — difficulty ramps forever, until your cardboard armor fails.
- **Skills with score** — 8 upgrades (Trigger Finger, Shotgun Diplomacy, Turbo Socks, Snack Magnet...)
- **Login with just a name** — no password, stored in `localStorage`.
- **Leaderboard** — top scores per name on this browser, with rank titles.
- **Effects** — particles, screen shake, neon trails, combo streaks, drifting space chatter.

## Controls
- Drag anywhere (or `A` / `D` / `←` `→`) to fly
- Auto-fire is always on
- `E` or the big circle = MEGA BEAM
- `Esc` = pause

## Run
```
npm install
npm run dev
```
